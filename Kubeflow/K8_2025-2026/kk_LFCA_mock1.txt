QUESTION 01: FIND FILES AND FILTER PERMISSIONS
=====================================================================
Question 1 of 17

Weight: 8/102

In the /opt/findme/ directory you will find 10,000 files. You need to filter out specific files

Find all files that have the executable permission bit enabled for the user that owns them. Redirect the output of the find command to the /opt/foundthem.txt file.
Find all files that have the SETUID permission enabled and delete them.
Find any file that is larger than 1KB and copy it to the /opt/ directory

Found files with executable permission?

Deleted files with SETUID permission?

Is the file larger than 1KB moved to /opt?



TASK:
1. Find files with owner executable permission.
2. Delete files with SETUID permission.
3. Copy files larger than 1KB to /opt/.

COMMANDS:

# Find owner-executable files
find /opt/findme/ -type f -perm -u=x > /opt/foundthem.txt

# Delete SETUID files
find /opt/findme/ -type f -perm -4000 -delete

# Copy files larger than 1KB
find /opt/findme/ -type f -size +1k -exec cp -t /opt/ {} +

# Verify
cat /opt/foundthem.txt
find /opt/findme/ -type f -perm -4000
ls -lh /opt/

ANSWERS:
Found executable files? YES
SETUID files deleted? YES
Files larger than 1KB copied? YES

QUESTION 02: BASH SCRIPT AND SYSTEM-WIDE CRON
=====================================================================


Question 2 of 17

Weight: 6/102
Perform the following two tasks:

Create a bash script that recursively copies the /var/www/ directory into the /opt/www-backup/ directory

Save your script at /opt/script.sh. Remember, the script file you create also has to be executable.

Make sure that your script /opt/script.sh automatically runs every day at 4AM. More specifically, create a cron job that runs that script every day at 4AM. Put this in the system-wide cron table (not root's local cron table) and make sure the script executes under the root user.


Is the /opt/script.sh script executable?

Is the script configured right?

Is system-wide cron table updated?





TASK:
1. Create /opt/script.sh.
2. Recursively copy /var/www/ to /opt/www-backup/.
3. Make script executable.
4. Run every day at 4 AM as root.
5. Use system-wide cron table.

COMMANDS:

# Create script
cat > /opt/script.sh <<'EOF'
#!/bin/bash
cp -a /var/www /opt/www-backup
EOF

# Make executable
chmod +x /opt/script.sh

# Add system-wide cron job
echo "0 4 * * * root /opt/script.sh" >> /etc/crontab

# Verify
ls -l /opt/script.sh
cat /opt/script.sh
cat /etc/crontab

ANSWERS:
Script executable? YES
Script configured correctly? YES
System-wide cron updated? YES

TASK:

1. Disk = /dev/vde (2GB).
2. Create two partitions of 500MB each.
3. First partition = EXT4.
4. Second partition = XFS.
5. Mount at /part1 and /part2.
6. Configure persistent mounting.

COMMANDS:

# SSH into node01
ssh bob@node01

# Open fdisk
sudo fdisk /dev/vde

# Inside fdisk enter:
n
p
1
<Enter>
+500M

n
p
2
<Enter>
+500M

w

# Refresh partition table
sudo partprobe /dev/vde

# Create filesystems
sudo mkfs.ext4 /dev/vde1
sudo mkfs.xfs /dev/vde2

# Create directories
sudo mkdir -p /part1 /part2

# Mount partitions
sudo mount /dev/vde1 /part1
sudo mount /dev/vde2 /part2

# Get UUIDs
UUID1=$(sudo blkid -s UUID -o value /dev/vde1)
UUID2=$(sudo blkid -s UUID -o value /dev/vde2)

# Persistent mounting
echo "UUID=$UUID1 /part1 ext4 defaults 0 2" | sudo tee -a /etc/fstab

echo "UUID=$UUID2 /part2 xfs defaults 0 0" | sudo tee -a /etc/fstab

# Verify
sudo mount -a
lsblk -f
df -hT

ANSWERS:
Volume mounted on /part1? YES
Volume mounted on /part2? YES
/dev/vde1 persistent? YES
/dev/vde2 persistent? YES
