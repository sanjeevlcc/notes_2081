2.1 HARDWARE AND SOFTWARE COMPONENTS
==================================================================

A. HARDWARE
------------------------------------------------------------------
Hardware refers to the physical parts of a computer or IT system
that we can see and touch.

Examples:
    - Keyboard
    - Mouse
    - Monitor
    - CPU
    - RAM
    - Hard Disk / SSD
    - Printer
    - Network Card
    - Router


MAIN COMPONENTS OF COMPUTER HARDWARE
------------------------------------------------------------------

1. INPUT DEVICES
   Used to enter data into a computer.

   Examples:
   - Keyboard
   - Mouse
   - Scanner
   - Microphone
   - Webcam

   Example:
   When we type "HELLO" using a keyboard, the keyboard sends
   the input to the computer.


2. PROCESSING DEVICES
   Used to process data and execute instructions.

   Main device:
   - CPU (Central Processing Unit)

   CPU contains:
   - ALU (Arithmetic Logic Unit)
   - CU (Control Unit)
   - Registers

   Example:
   10 + 20 = 30

   ALU performs the arithmetic operation.


3. MEMORY
   Memory stores data and instructions.

   Types:

   a. RAM
      - Temporary memory
      - Volatile
      - Data is lost when power is turned off

      Example:
      Microsoft Word uses RAM while you are working on a document.

   b. ROM
      - Permanent/non-volatile memory
      - Stores important startup instructions

   c. Cache Memory
      - Very fast memory
      - Located close to/within the CPU
      - Stores frequently used data and instructions


4. STORAGE DEVICES
   Used for permanent storage.

   Examples:
   - HDD
   - SSD
   - USB Flash Drive
   - Memory Card
   - CD/DVD

   Example:
   A student's "Exam_Result.xlsx" file can be stored on an SSD.


5. OUTPUT DEVICES
   Used to display processed information.

   Examples:
   - Monitor
   - Printer
   - Speaker
   - Projector

   Example:
   After calculating student marks, the result is displayed
   on the monitor.


------------------------------------------------------------------
B. SOFTWARE
------------------------------------------------------------------

Software is a collection of programs/instructions that tells
computer hardware what to do.

Examples:
    - Windows
    - Linux
    - MS Word
    - Excel
    - Google Chrome
    - MySQL
    - Python


TYPES OF SOFTWARE
------------------------------------------------------------------

1. SYSTEM SOFTWARE

   System software controls and manages computer hardware.

   Examples:
   - Windows
   - Linux
   - macOS
   - Device Drivers
   - Operating Systems

   Example:
   Windows manages CPU, RAM, keyboard, mouse and other devices.


2. APPLICATION SOFTWARE

   Application software is designed to perform specific
   user-oriented tasks.

   Examples:
   - MS Word -> Document writing
   - MS Excel -> Spreadsheet and calculations
   - Photoshop -> Image editing
   - Chrome -> Web browsing
   - VLC -> Media playing

   Example:
   A teacher uses MS Excel to calculate students' marks.


3. UTILITY SOFTWARE

   Utility software helps maintain, protect and manage
   computer systems.

   Examples:
   - Antivirus
   - Disk Cleanup
   - Backup Software
   - File Compression Software

   Example:
   Antivirus software scans a computer for malware.


------------------------------------------------------------------
HARDWARE VS SOFTWARE
------------------------------------------------------------------

Hardware:
    - Physical component
    - Can be touched
    - Examples: CPU, keyboard, RAM

Software:
    - Set of programs/instructions
    - Cannot be physically touched
    - Examples: Windows, Excel, Chrome


SIMPLE EXAMPLE
------------------------------------------------------------------

Computer System = Hardware + Software

Example:

Hardware:
    Keyboard + CPU + RAM + SSD + Monitor

Software:
    Windows + MS Excel

Process:
    User enters marks
          ↓
    Keyboard
          ↓
    CPU processes data
          ↓
    RAM temporarily stores data
          ↓
    Excel performs calculation
          ↓
    Monitor displays result

2.2 DATABASE MANAGEMENT SYSTEMS (DBMS)
==================================================================

DEFINITION
------------------------------------------------------------------

A Database Management System (DBMS) is software used to create,
store, organize, manage, retrieve and manipulate data in a database.

Examples:
    - MySQL
    - PostgreSQL
    - Oracle Database
    - Microsoft SQL Server
    - MongoDB


DATABASE
------------------------------------------------------------------

A database is an organized collection of related data.

Example:

STUDENT DATABASE

Student_ID    Name       Age    Program
------------------------------------------------
101           Ram        20     BCA
102           Sita       21     BCA
103           Hari       20     BCSIT


WHY DO WE NEED DBMS?
------------------------------------------------------------------

Without DBMS:
    - Data may become duplicated
    - Difficult to search
    - Difficult to update
    - Difficult to maintain security
    - Difficult to manage large amounts of data

With DBMS:
    - Easy data storage
    - Easy data retrieval
    - Data security
    - Data consistency
    - Backup and recovery
    - Multiple users can access data


MAIN FUNCTIONS OF DBMS
------------------------------------------------------------------

1. Data Storage
2. Data Retrieval
3. Data Manipulation
4. Data Security
5. Backup and Recovery
6. Data Sharing
7. Data Integrity


EXAMPLE OF DBMS
------------------------------------------------------------------

Suppose a college has:

    5,000 Students
    100 Teachers
    50 Courses
    10,000 Exam Records

A DBMS can store and manage all these records.

Example query:

    Find all students studying BCA.

The DBMS searches the database and returns the required records.


BASIC DATABASE TERMS
------------------------------------------------------------------

1. TABLE
   Stores data in rows and columns.

2. ROW / RECORD
   Represents one complete data entry.

3. COLUMN / FIELD
   Represents one attribute.

4. PRIMARY KEY
   Uniquely identifies each record.

Example:

Student_ID = Primary Key


5. FOREIGN KEY
   Connects one table with another table.


SIMPLE RELATIONSHIP EXAMPLE
------------------------------------------------------------------

STUDENT TABLE

Student_ID    Name       Course_ID
-----------------------------------
101           Ram        C01
102           Sita       C02
103           Hari       C01


COURSE TABLE

Course_ID     Course_Name
--------------------------
C01           BCA
C02           BCSIT


Here:

Student_ID = Primary Key in STUDENT table

Course_ID = Primary Key in COURSE table

Course_ID in STUDENT table = Foreign Key


SQL EXAMPLE
------------------------------------------------------------------

To display all students:

SELECT * FROM Student;


To find BCA students:

SELECT * FROM Student
WHERE Course_ID = 'C01';


To add a student:

INSERT INTO Student
VALUES (104, 'Gita', 'C01');

2.3 NETWORKING AND TELECOMMUNICATIONS
==================================================================

A. COMPUTER NETWORK
------------------------------------------------------------------

A computer network is a group of interconnected computers/devices
that communicate and share resources.

Example:

    Computer A -------- Router -------- Computer B
                             |
                           Printer






PURPOSES OF NETWORKING
------------------------------------------------------------------

    1. Resource Sharing
    2. File Sharing
    3. Communication
    4. Internet Access
    5. Data Sharing
    6. Centralized Management
    7. Remote Access
    

TYPES OF NETWORK
------------------------------------------------------------------

1. PAN
   Personal Area Network

   Small network around one person.

   Example:
       Mobile phone connected to Bluetooth earphones.


2. LAN
   Local Area Network

   Network within a small geographical area.

   Example:
       Computer network inside a college laboratory.


3. MAN
   Metropolitan Area Network

   Covers a city or large campus area.

   Example:
       Network connecting different branches within a city.


4. WAN
   Wide Area Network

   Covers large geographical areas.

   Example:
       The Internet.







NETWORK DEVICES
------------------------------------------------------------------

1. HUB
   Connects multiple devices in a network.

2. SWITCH
   Connects devices in a LAN and forwards data to the
   appropriate device.

3. ROUTER
   Connects different networks and forwards packets.

4. MODEM
   Converts signals for communication between a local network
   and an Internet service.

5. ACCESS POINT
   Provides wireless network access.

6. NETWORK INTERFACE CARD (NIC)
   Allows a computer/device to connect to a network.





NETWORK TOPOLOGIES
------------------------------------------------------------------ 

1. BUS TOPOLOGY
   All devices share one main communication cable.

2. STAR TOPOLOGY
   All devices connect to a central device.

       Computer1
           |
           |
    Computer--Switch--Computer
           |
           |
       Computer2

3. RING TOPOLOGY
   Devices are connected in a circular structure.

4. MESH TOPOLOGY
   Devices have multiple connections with each other.

5. TREE TOPOLOGY
   Combination of hierarchical structures.

A. CLOUD COMPUTING
==================================================================

DEFINITION
------------------------------------------------------------------

Cloud computing is the delivery of computing resources such as
servers, storage, databases, networking and software over the
Internet.

Simple meaning:

Instead of storing and processing everything on your own computer,
you can use computing resources through the Internet.


EXAMPLES
------------------------------------------------------------------

- Google Drive
- OneDrive
- Dropbox
- AWS
- Microsoft Azure
- Google Cloud


EXAMPLE
------------------------------------------------------------------

Suppose your laptop has only 128 GB storage.

Instead of storing a 50 GB collection of files locally,
you can store them in cloud storage.

Laptop
   ↓
Internet
   ↓
Cloud Storage
   ↓
Your Files


ADVANTAGES
------------------------------------------------------------------

1. Access from anywhere
2. Scalable
3. Lower hardware requirements
4. Backup
5. Resource sharing
6. Flexible pricing


TYPES OF CLOUD
------------------------------------------------------------------

1. PUBLIC CLOUD
   Cloud resources are provided to many users.

2. PRIVATE CLOUD
   Cloud infrastructure is dedicated to one organization.

3. HYBRID CLOUD
   Combination of public and private cloud.


CLOUD SERVICE MODELS
------------------------------------------------------------------

1. IaaS
   Infrastructure as a Service

   Provides:
   - Virtual machines
   - Storage
   - Networking

2. PaaS
   Platform as a Service

   Provides:
   - Development platform
   - Runtime environment
   - Development tools

3. SaaS
   Software as a Service

   Provides ready-to-use software.

   Example:
   Google Docs / Microsoft 365

D. BLOCKCHAIN
==================================================================

DEFINITION
------------------------------------------------------------------

Blockchain is a distributed digital ledger technology that stores
records in blocks linked together using cryptographic techniques.

Simple idea:

Data → Block → Block → Block → Block


IMPORTANT FEATURES
------------------------------------------------------------------

1. Decentralization
2. Transparency
3. Security
4. Immutability
5. Distributed Ledger


HOW BLOCKCHAIN WORKS
------------------------------------------------------------------

Step 1:
A transaction is created.

Step 2:
Transaction is verified by the network.

Step 3:
Verified transactions are grouped into a block.

Step 4:
The block is added to the blockchain.

Step 5:
The record becomes part of the distributed ledger.


EXAMPLE
------------------------------------------------------------------

Person A sends digital currency to Person B.

A
 ↓
Transaction
 ↓
Network Verification
 ↓
Block
 ↓
Blockchain
 ↓
B


APPLICATIONS
------------------------------------------------------------------

- Cryptocurrency
- Supply chain management
- Digital identity
- Banking
- Smart contracts
- Healthcare records
- Voting systems

E. INTERNET OF THINGS (IoT)
==================================================================

DEFINITION
------------------------------------------------------------------

IoT stands for Internet of Things.

IoT is a system in which physical devices are connected to the
Internet so that they can collect, exchange and sometimes act
on data.

Simple formula:

IoT = Physical Device + Sensor + Internet + Data + Action


EXAMPLES
------------------------------------------------------------------

- Smart watch
- Smart TV
- Smart refrigerator
- Smart bulb
- Smart security camera
- Smart agriculture system
- Smart home


EXAMPLE: SMART HOME
------------------------------------------------------------------

Temperature Sensor
        ↓
     Internet
        ↓
     Cloud/App
        ↓
   User's Mobile
        ↓
   Air Conditioner

If temperature becomes too high:

Sensor detects temperature
        ↓
System processes data
        ↓
AC can be switched ON automatically


IoT COMPONENTS
------------------------------------------------------------------

1. Sensors
   Collect data.

2. Devices
   Physical objects.

3. Connectivity
   Wi-Fi, Bluetooth, 4G/5G, etc.

4. Data Processing
   Processes collected data.

5. Application
   Allows users to view/control the system.


IoT APPLICATIONS
------------------------------------------------------------------

1. Smart Home
2. Smart City
3. Smart Agriculture
4. Healthcare
5. Transportation
6. Manufacturing
7. Security
8. Energy Management

G. BIG DATA
==================================================================

Big Data refers to extremely large and complex datasets that
traditional data-processing methods may struggle to handle.

Common characteristics:

5 Vs of Big Data:

1. Volume
   Large amount of data.

2. Velocity
   Data is generated rapidly.

3. Variety
   Different types of data.

4. Veracity
   Reliability/quality of data.

5. Value
   Useful information obtained from data.


EXAMPLE
------------------------------------------------------------------

Facebook/Instagram generates:

    Photos
    Videos
    Messages
    Comments
    Likes
    User activity

This creates huge amounts of data.
