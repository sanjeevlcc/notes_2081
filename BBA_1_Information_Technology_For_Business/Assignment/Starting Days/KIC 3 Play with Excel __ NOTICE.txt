============================================================
EXCEL STUDENT RESULT ANALYSIS PRACTICE
BASIC → INTERMEDIATE → ADVANCED
============================================================

DATASET STRUCTURE
------------------------------------------------------------

A  = S.N.
B  = Name
C  = Sub 1
D  = Sub 2
E  = Sub 3
F  = Sub 4
G  = Sub 5
H  = Total
I  = Percent
J  = Result
K  = Pass / Fail


============================================================
PHASE 1: BASIC EXCEL
============================================================

1. TOTAL MARKS
------------------------------------------------------------
Cell H2:

=SUM(C2:G2)

Drag down to H11.


2. PERCENTAGE
------------------------------------------------------------
Cell I2:

=H2/500*100

OR

=H2/5

Drag down.


3. RESULT / DIVISION
------------------------------------------------------------
Cell J2:

=IF(I2>=80,"Distinction",IF(I2>=60,"First Division",IF(I2>=50,"Second Division",IF(I2>=40,"Pass","Fail"))))

Drag down.


4. PASS / FAIL
------------------------------------------------------------
Cell K2:

=IF(I2>=40,"Pass","Fail")

Drag down.


5. AVERAGE / MEAN
------------------------------------------------------------

Sub 1:

=AVERAGE(C2:C11)

Sub 2:

=AVERAGE(D2:D11)

All subjects:

=AVERAGE(C2:G11)

Total Average:

=AVERAGE(H2:H11)


6. MAXIMUM
------------------------------------------------------------

Highest Sub 1:

=MAX(C2:C11)

Highest Total:

=MAX(H2:H11)


7. MINIMUM
------------------------------------------------------------

Lowest Sub 1:

=MIN(C2:C11)

Lowest Total:

=MIN(H2:H11)


8. MEDIAN
------------------------------------------------------------

Median Sub 1:

=MEDIAN(C2:C11)

Median Total:

=MEDIAN(H2:H11)


9. MODE
------------------------------------------------------------

=MODE.SNGL(H2:H11)


10. CENTRAL TENDENCY
------------------------------------------------------------

MEAN:

=AVERAGE(H2:H11)

MEDIAN:

=MEDIAN(H2:H11)

MODE:

=MODE.SNGL(H2:H11)







============================================================
PHASE 2: INTERMEDIATE EXCEL
============================================================

ADD THESE NEW COLUMNS:

L = Average
M = Highest Subject
N = Lowest Subject
O = Grade
P = Rank
Q = Attendance
R = Study Hours
S = Scholarship
T = Remarks


11. STUDENT AVERAGE
------------------------------------------------------------

L2:

=AVERAGE(C2:G2)


12. HIGHEST SUBJECT MARK
------------------------------------------------------------

M2:

=MAX(C2:G2)


13. LOWEST SUBJECT MARK
------------------------------------------------------------

N2:

=MIN(C2:G2)


14. GRADE
------------------------------------------------------------

O2:

=IF(I2>=80,"A+",IF(I2>=70,"A",IF(I2>=60,"B+",IF(I2>=50,"B",IF(I2>=40,"C","F")))))


15. RANK
------------------------------------------------------------

P2:

=RANK.EQ(H2,$H$2:$H$11,0)


16. RANDOM ATTENDANCE
------------------------------------------------------------

Q2:

=RANDBETWEEN(60,100)


17. RANDOM STUDY HOURS
------------------------------------------------------------

R2:

=RANDBETWEEN(1,8)


Decimal study hours:

=RANDBETWEEN(10,80)/10


18. SCHOLARSHIP
------------------------------------------------------------

Condition:

Percentage >= 80
AND
Attendance >= 75

S2:

=IF(AND(I2>=80,Q2>=75),"Yes","No")


19. REMARKS
------------------------------------------------------------

T2:

=IF(I2>=80,"Excellent",IF(I2>=60,"Good",IF(I2>=40,"Average","Needs Improvement")))


20. COUNT STUDENTS
------------------------------------------------------------

=COUNT(A2:A11)


21. COUNT PASS STUDENTS
------------------------------------------------------------

=COUNTIF(K2:K11,"Pass")


22. COUNT FAIL STUDENTS
------------------------------------------------------------

=COUNTIF(K2:K11,"Fail")


23. COUNT DISTINCTION STUDENTS
------------------------------------------------------------

=COUNTIF(J2:J11,"Distinction")


24. COUNTIFS
------------------------------------------------------------

Pass + Attendance >=75:

=COUNTIFS(K2:K11,"Pass",Q2:Q11,">=75")


Percentage >=80 AND Attendance >=80:

=COUNTIFS(I2:I11,">=80",Q2:Q11,">=80")


25. SUMIF
------------------------------------------------------------

Total marks of Pass students:

=SUMIF(K2:K11,"Pass",H2:H11)


26. AVERAGEIF
------------------------------------------------------------

Average percentage of Pass students:

=AVERAGEIF(K2:K11,"Pass",I2:I11)


27. STANDARD DEVIATION
------------------------------------------------------------

Sample SD:

=STDEV.S(H2:H11)

Population SD:

=STDEV.P(H2:H11)


28. VARIANCE
------------------------------------------------------------

=VAR.S(H2:H11)

OR

=VAR.P(H2:H11)

32. CORRELATION
------------------------------------------------------------

Study Hours vs Percentage:

=CORREL(R2:R11,I2:I11)


Attendance vs Percentage:

=CORREL(Q2:Q11,I2:I11)


Interpretation:

+1 = Perfect Positive Relationship
0  = No Linear Relationship
-1 = Perfect Negative Relationship



33. RANDOM AGE
------------------------------------------------------------

V2:

=RANDBETWEEN(18,25)


34. RANDOM MARKS
------------------------------------------------------------

=RANDBETWEEN(20,100)


35. RANDOM ATTENDANCE
------------------------------------------------------------

=RANDBETWEEN(50,100)


36. RANDOM NAME
------------------------------------------------------------

=INDEX({"Ram","Sita","Hari","Gita","Shyam","Laxmi","Krishna","Radha","Bishal","Mina"},RANDBETWEEN(1,10))


37. XLOOKUP
------------------------------------------------------------

Create a separate table:

Grade       Description
A+          Outstanding
A           Excellent
B+          Very Good
B           Good
C           Satisfactory
F           Fail

Formula:

=XLOOKUP(O2,$W$2:$W$7,$X$2:$X$7)


38. FILTER
------------------------------------------------------------

Show only Pass students:

=FILTER(A2:T11,K2:K11="Pass")


Show only Distinction students:

=FILTER(A2:T11,J2:J11="Distinction")


39. SORT
------------------------------------------------------------

Sort according to Total Marks:

=SORT(A2:T11,8,-1)


40. UNIQUE
------------------------------------------------------------

Find unique faculties:

=UNIQUE(W2:W11)


41. IF + AND
------------------------------------------------------------

Scholarship:

=IF(AND(I2>=80,Q2>=75),"Scholarship","No Scholarship")


42. IF + OR
------------------------------------------------------------

Academic support:

=IF(OR(I2<50,Q2<60),"Needs Support","Normal")
